# 🎺 Trumpet Toolkit

トランペット奏者のためのオールインワン練習Webアプリです。ブラウザだけで動作し、インストールやサーバーサイドの処理は不要です。GitHub Pagesでそのまま公開できます。

公開URL: https://<ユーザー名>.github.io/<リポジトリ名>/

## 主な機能

| 機能 | 内容 |
|---|---|
| チューナー | マイク入力をリアルタイム解析し、記譜音・実音・周波数・セントのずれを針メーターで表示。ピッチ安定性グラフと基準音（ドローン）再生付き |
| メトロノーム | 20〜300 BPM、1〜12拍子、細分化（8分・3連・16分）、1拍目アクセント、タップテンポ、自動テンポアップ |
| 運指表 | 記譜 F#3〜C6 の3本ピストン標準運指、代替運指、スライド調整の注意、試聴、運指クイズ |
| スケール | 10種類のスケールを任意の調・オクターブで表示し、模範音を再生（再生中の音をハイライト） |
| 移調 | 実音や他楽器の楽譜の音名を指定楽器の記譜音へ変換。調の変換 |
| リップスラー | 運指・倍音範囲・パターンから練習音列を生成して再生 |
| 練習メニュー | 練習時間と重点項目から時間配分付きのメニューを作成 |
| 練習記録 | ブラウザ内（localStorage）に保存。総時間・日別・カテゴリ別グラフ、CSV出力 |

ヘッダーの設定で楽器（9種）、基準ピッチ（A4 = 430〜450 Hz）、♭表記、音量を切り替えると、すべての機能に反映されます。設定は自動保存されます。

## ローカルで動かす

マイクの利用には安全なコンテキスト（HTTPS または localhost）が必要です。index.html をファイルとして直接開くのではなく、ローカルサーバー経由で開いてください。

    python -m http.server 8000

ブラウザで http://localhost:8000 を開きます。

## GitHub Pagesへのデプロイ

1. リポジトリのルートに index.html / style.css / app.js を配置して main ブランチへ push する
2. GitHub のリポジトリページで Settings → Pages を開く
3. Build and deployment の Source で「Deploy from a branch」を選択する
4. Branch に main、フォルダに / (root) を指定して Save する
5. 数分後、Pages の画面に表示されるURLにアクセスする

GitHub Pages は HTTPS で配信されるため、チューナーのマイク機能もそのまま利用できます。

## 使い方のヒント

- 初回にチューナーを開始すると、ブラウザがマイクの使用許可を求めます。許可してください。
- 基準音を鳴らしながらチューナーを使う場合は、イヤホンを使うと基準音をマイクが拾いにくくなります。
- 周囲が騒がしいときは、チューナーの「ノイズゲート」を上げると誤検出が減ります。
- メトロノームタブ表示中は、スペースキーでスタート/ストップできます。
- iPhone では本体の消音スイッチがオンの場合に音が出ないことがあります。
- 練習記録はブラウザごとに保存されます。ブラウザのサイトデータを消去すると記録も消えるため、CSV出力で定期的にバックアップしてください。

## 対応ブラウザ

Web Audio API と getUserMedia に対応した最新版の Chrome / Edge / Firefox / Safari を対象としています。実機での確認状況は STATUS.md を参照してください。

## 旧バージョン（Streamlit版）

v1 の Streamlit 版は legacy/trumpet_app.py に保管しています。

    pip install "streamlit>=1.40" numpy pandas
    streamlit run legacy/trumpet_app.py
